# AGENTS.md（示例：放在办文工作区根目录）

本目录是公文拟制工作区，使用 gongwen MCP 服务办理公文。

- 起草、修改、审核公文时，通过 gongwen 的工具推进流程，不要自己直接写公文正文文件。
- 遇到 human_actions（任务确认、提纲确认、材料准入、人工送审等），把问题和选项原样告诉用户，
  由用户在终端执行 `gongwen task confirm …`，你不能代为确认。
- 不得编造事实、数字、依据和批准事项；发文字号、成文日期、签发人由真实办理流程填写。
- 检查已有文稿用 text_check；查依据用 policy_search；说明规则时区分“条例/国标/实务”。
- 想改稿时用 revision_propose 提交建议，请用户采纳。
