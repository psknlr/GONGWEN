# 技能2 材料解析

## 目的
原始材料不变、结构化副本可加工、每个抽取结果都能回到原位置（文件、段落、表格单元格、页码行号）。“系统不会先把材料上传给模型再判断是否敏感”。

## 准入（先于任何模型）
- 密级标志（绝密、机密、秘密等）→ 任何路线一律禁止进入，原件立即删除；
- 工作秘密、内部、敏感 → 公开研发版禁止；单位批准环境须按制度开启并人工确认；
- 个人信息（身份证号校验位、手机号、银行卡 Luhn、邮箱）、隐藏内容、提示注入 → 需人工确认；
- 多份公开材料汇聚后可能产生敏感性（聚合风险）→ 提示人工判断；
- 模型通道添加的材料不能申报属性，未申报的一律人工确认。

## 解析输出（SourceBundle）
- 段落、表格单元格（如 `Sheet1!B3`、`table1.r2.c3`）、PDF 页与行；
- 表注、脚注与表格的关系（如“仅统计已验收项目”限定口径）；
- XLSX 公式本地重算，与缓存值不一致时报告；
- 无文本层的扫描 PDF 明确警告，不臆造 OCR 结果。

## 必须由人完成
“材料准入确认”节点：逐份确认属性或不准入并删除。该节点永远不能被无头模式自动接受。

## 如何调用
- 命令行（人申报属性）：`gongwen task add <任务> <文件> --clearance 公开`；
- MCP：`material_add`（只能添加工作区内文件，且须人工确认准入）。

## 失败与退出
不支持的格式、解析失败、准入禁止都会写入审计日志并在状态中可见，不会悄悄跳过。
