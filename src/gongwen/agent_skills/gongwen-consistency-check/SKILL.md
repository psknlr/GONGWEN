# 技能8 跨材料一致性检查

## 检查项
| 检查 | 示例问题 | 规则来源 |
|---|---|---|
| 附件说明 ↔ 附件 | 附件说明列了附件2，后面没有附件2；标题不一致 | GB/T 9704—2012 7.3.7（国标） |
| 附件名称标点 | “经费测算表。”名称后加了标点 | GB/T 9704—2012 7.3.4（国标） |
| 交叉引用 | 正文写“见附件3”，附件说明只有两个 | 国标 7.3.7 |
| 表格合计 | 60+40 合计写成 110 | 条例第二十条（四）数字准确 |
| 正文 ↔ 账本 | 句子引用了 F-003，句中数值与账本不一致 | 系统事实账本规则 |
| 同一事项多份文稿 | 请示写“拟建 12 个”，汇报材料写“已建成 12 个” | 系统事实账本规则 |

## 输出
一致性报告：检查范围、发现项（类型、位置、双方取值、建议）。机械性问题（附件名称标点、附件标题同步）可自动修订；其余转人工。

## 如何调用
- 对已有文稿：MCP `text_check`，或命令行 `gongwen check <文件>`（含附件说明与表格合计检查）；
- 任务内：审校阶段自动运行，结果见 `issues_list` / `gongwen task issues`。
