# 技能11 版式编译与检查

## 主要参数（GB/T 9704—2012）
- A4；天头 37mm±1mm，订口 28mm±1mm；版心 156mm×225mm；
- 一般每面 22 行、每行 28 字（“一般”属条件性要求）；正文 3 号仿宋体；
- 发文机关标志上边缘至版心上边缘 35mm（推荐小标宋、红色）；发文字号之下 4mm 处红色分隔线；
- 标题 2 号小标宋体，红色分隔线下空二行；
- 页码 4 号半角宋体阿拉伯数字，数字左右各放一条一字线，一字线距版心下边缘 7mm，单页居右空一字、双页居左空一字；
- 版记分隔线：首条与末条推荐 0.35mm，中间 0.25mm；
- 信函格式、命令（令）格式、纪要格式的特殊规定按条款处理。

## 两类核验分开报告
1. 生成参数核验：回读 DOCX 的页面设置、字体字号、行距网格；
2. 实际渲染核验：LibreOffice 转 PDF 后测量。“公文首页必须显示正文”不满足且主送机关较多时，按 7.3.2 把主送机关移至版记。

## 诚实报告
国标只规定字体类别；仿宋_GB2312、方正小标宋简体等字库名属实务，且为授权字库。本机缺字库时渲染预览以开源字体替代，报告标为“已替代：……（开源替代字体，仅供预览）”，不声称已完全满足版式。发文字号、成文日期、签发信息不用生成时间或模型猜测填充。

## 公文模板
按公文模板（任务创建时的 `--template` 或配置 `layout.template`）排版时，核验以模板的生效参数为准；模板对国标的每项偏离（条款与强度）列为 `TEMPLATE`、`TPL-DEV` 核验项，不得隐去。模板的单位信息只补全文稿中空缺的版头、版记要素。

## 如何调用
- 已有文稿排版：`gongwen format <文件> -o <输出目录> [--template <模板>]`（页眉标“排版稿”，正文内容未经核验）；
- 渲染预览：`gongwen preview <文件或任务> [--template <模板>]`（页面图像与核验结果，preview.html）；
- 任务内：排版检查阶段自动运行，报告见审阅工作台“版式”页，页面图像见 `/preview/<任务>`。
