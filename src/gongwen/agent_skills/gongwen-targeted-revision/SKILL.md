# 技能10 定向修订

## 原则
- 只改与问题直接相关的最少内容，不重写全文；
- 每个补丁都有前后文本、理由、关联问题和语义变化记录；
- 语义增强、扩大、删除条件、状态升级 → 不自动应用，转人工；
- 人写的句子不被系统自动推翻，只提出建议；
- 自动修订有轮数上限（默认 2 轮），仍未解决的问题转“审校问题人工处理”节点；
- 修订后重新审校；已绑定审批记录的版本发生实质修改，审批失效，须报原签批人复审（条例第二十五条（一））。

## 修改入口（都由人发起）
| 方式 | 命令 |
|---|---|
| 修改意见（需配置模型） | `gongwen task revise <任务> --instruction "压缩第一部分"` |
| 改写一句 | `gongwen task revise <任务> --edit s-004="新的句子"` |
| 关键事实变更 | `gongwen task revise <任务> --fact F-003=40 --reason 核减` |
| 采纳模型提交的修改建议 | `gongwen task apply <任务> PR-001` |

模型通道（对话代理、MCP 客户端）只能用 `revision_propose` 提交修改建议，不能直接改稿或采纳建议。
