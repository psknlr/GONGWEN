# 技能6 方案与提纲规划

## 目的
先定“意图—依据—事实—措施—表达”，再动笔。系统可以提示缺失和候选方案，但不替人决定预算、规模、责任和承诺。

## 规划内容
1. 段落计划：每段承担明确功能（依据 / 事实 / 分析 / 措施 / 条件 / 要求 / 请求 / 结语），不写空泛表态段；
2. 措施表：措施只能来自材料中的计划、要求或人工确认的事项；每项列出八要素，缺失的要素标“未明确”而不是补写；
3. 候选方案：只有材料本身提到多种做法（如“试点”与“全面推开”）时才列出供选择；
4. 待确认问题：资金来源、责任单位、时限、是否需要会签等；
5. 附件计划：经费测算等明细放附件，正文写合计并注明“测算明细见附件”。

## 必须由人完成
“提纲与措施确认”节点，可在 data 中：
- `confirm_facts`：确认已核实的关键数据；
- `add_facts`：补充人工事实（如资金来源），系统会重新规划后再次请你确认；
- `drop_measures` / `confirm_measures`：删除或确认措施；
- `alternative`：选择候选方案。

示例：`gongwen task confirm <任务> <节点> edit --data '{"confirm_facts": ["F-002", "F-003"]}'`

## 无头模式
`--accept outline_confirm` 只在启动者明确授权时自动接受（默认选项“确认提纲与措施”），且全程留痕。
