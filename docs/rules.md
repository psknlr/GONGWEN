# 规则库与来源层级

规则库在 `src/gongwen/rules/registry.py`（规则库版本号写入每个送审包），共 86 条；检查器 31 个，分为文种、语言、语义、依据、负担与文风、一致性、要素格式七组。

## 一、来源层级决定措辞

| 层级 | 含义 | 答复与问题报告中的措辞 |
|---|---|---|
| 法律法规 | 法律、行政法规（如《公平竞争审查条例》） | “……规定” |
| 条例 | 《党政机关公文处理工作条例》等党内法规 | “条例规定” |
| 国标 | GB/T 9704—2012 原文条款 | “国标规定” |
| 标准 | GB/T 15834—2011、GB/T 15835—2011 | “标准规定” |
| 政策文件 | 如《整治形式主义为基层减负若干规定》、国办发〔2018〕115号 | 写明文件名称 |
| 实务 | 国标与条例未规定的通行做法（结束语、称谓等） | “实务通常”“多数单位”，不得说成“规定” |
| 单位制度 | 本单位公文处理细则 | 写明制度名称 |
| 待核 | 存在分歧或未获权威确认 | 主动说明分歧 |
| 旧规 | 已停止执行的规定（如 2000 年《国家行政机关公文处理办法》） | “已废止，不应引用” |

规则层级分布：条例 38、实务 21、标准 12、国标 10、政策文件 3、法律法规 1、单位制度 1。

## 二、条件性要求只提示

标准中带“一般”“推荐”“可以”“原则上”的要求标记为条件性（`conditional=True`），违反时最高只报“一般”问题，不编码为没有例外的硬错误。例如：

- 每面 22 行、每行 28 字是“一般”安排，特定情况可以适当调整（GB/T 9704—2012 5.2.3）；
- 发文机关标志“推荐使用小标宋体字，颜色为红色”（7.2.4）；
- 上行文原则上主送一个上级机关、一般不得越级行文（条例第十四条、第十五条）。

单位配置只能调整“实务”“单位制度”层级规则的严重程度，不能关闭条例、国标、标准规则。

## 四、GB/T 9704—2012 版式参数

版式配置 `src/gongwen/layout/profiles/gbt9704-2012.yaml` 为每个参数标注条款与强度（规定 / 一般 / 推荐 / 可以 / 实务 / 推算）：

| 要素 | 参数 | 条款 | 强度 |
|---|---|---|---|
| 纸张 | A4（210mm×297mm） | 5.1 | 规定 |
| 页边与版心 | 天头 37mm±1mm、订口 28mm±1mm、版心 156mm×225mm | 5.2.1 | 规定 |
| 行与字 | 一般每面 22 行、每行 28 字 | 5.2.3 | 一般 |
| 行距 | 579 缇（28.95 磅）：225mm÷22 行约 28.99 磅，向下取整到缇，22 行才不超出版心（国标不给磅值） | — | 实务 |
| 正文 | 3 号仿宋体 | 5.2.2 | 一般 |
| 发文机关标志 | 上边缘至版心上边缘 35mm；推荐小标宋体、红色 | 7.2.4 | 推荐 |
| 红色分隔线 | 发文字号之下 4mm 处，与版心等宽 | 7.2.7 | 规定 |
| 标题 | 2 号小标宋体，红色分隔线下空二行 | 7.3.1 | 一般 |
| 层次标题 | 一级黑体、二级楷体、三四级仿宋 | 7.3.3 | 一般 |

| 页码 | 4 号半角宋体阿拉伯数字，一字线距版心下边缘 7mm，单页居右空一字、双页居左空一字 | 7.5 | 一般 |
| 信函格式 | 发文机关标志上边缘距页面上边缘 30mm；首条线距下 4mm；末条线距页面下边缘 20mm；线长 170mm | 10.1 | 规定 |

## 五、常被误当作现行规定的旧表述

| 表述 | 实际情况 |
|---|---|
| 每排最多 3 个印章、两印章相距不超过 3mm | 1999 版国标；2012 版要求印章之间排列整齐、互不相交或相切 |
| 纪要不加盖印章 | 1999 版国标；2012 版 10.3 无此句，属实务 |
| 成文日期用汉字数字 | 旧办法习惯；2012 版国标 7.3.5.4 要求阿拉伯数字 |
| 引用 2000 年《国家行政机关公文处理办法》 | 已于 2012 年 7 月 1 日停止执行（条例第四十二条），依据库中标为已废止，引用时报“依据不适用” |

## 六、自动修订的边界

`gongwen check --fix` 与定向修订只自动处理不改变语义的机械性问题：标点、数字与日期写法、标题末尾标点、附件说明序号与标点、主送机关冒号、层次序数格式、易混字词。文种、结束语、称谓、行文关系、事实状态、数字取值、依据等问题只给出建议，由人决定如何修改；每处自动修订都列出修改前后，供人工复核。

## 七、追加本单位规则

1. 在单位配置档（`src/gongwen/profiles/*.yaml` 或数据目录）中配置可用文种、单位程序（触发关键词 → 程序）与自称；
2. 以插件追加检查器：实现 `def my_checker(ctx: CheckContext) -> list[ReviewIssue]`，在插件中注册到 `rules.GROUPS`；
3. 新规则须写明来源层级与条款，条件性规则标记 `conditional=True`。
